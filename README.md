# Cat Mafia

A cozy 8-bit game about the shop cats of Istanbul. Every shop has a cat, and no shop stays open without "protection." You play the Don, making the rounds.

Built with Phaser 3 and Vite. Made for phone screens, played in the browser.

```bash
npm install
npm run dev     # local server (also reachable from your phone on the same Wi-Fi)
npm run build   # static build in dist/
```

Pushing to `main` deploys to GitHub Pages.

## Art

- Sprites and animation: Retro Diffusion.
- Shop fronts: concept art from Gemini (`art/concepts/`), turned into true pixel art with Retro Diffusion's `rd_pro__pixelate`.
